# Trishi / Yeon's birthday surprise 🎂

A clickable Shinchan birthday mini-website, signed **by ash ♡**.

## Run
Open `index.html` in a browser. Keep `style.css`, `script.js` and `assets/` beside it.

## Publish
In GitHub Pages settings, choose `main` and `/ (root)`. The animated GIFs are stored locally.

## Personalization
Edit the Hinglish letter in `index.html` and names in `script.js`.
10 distinct selected photos appear in the gallery.

**Privacy:** Publishing on GitHub Pages makes these photos publicly accessible.
